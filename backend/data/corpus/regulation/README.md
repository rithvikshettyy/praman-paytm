# regulation/

Regulator texts the assistant may quote to anyone, whatever her insurer: IRDAI circulars and master circulars, the Insurance Ombudsman Rules, RBI directions and FAQs.

Primary sources only. Save the regulator's own PDF, list it in `../sources.yaml` with `layer: regulation`, its `source_url` and `effective_date`, and keep `verified_by: UNVERIFIED` until someone has checked it against the original. Never paraphrase a regulation into a file here.

This README is not ingested; only files listed in `sources.yaml` are.
